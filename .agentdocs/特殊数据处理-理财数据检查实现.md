# 特殊数据处理-理财数据检查实现

## 需求概述

在已有“特殊数据处理”页面新增“理财数据检查”模块，用于检测当前用户支付宝余额宝相关交易，并由用户确认是否批量标为“不计”。

## 实现逻辑

- 前端在 `frontend/js/special-data-processing.js` 新增“理财数据检查”卡片区域，按钮文案为“检查理财数据”。
- 点击按钮后调用 `POST /api/v1/special-data-processing/wealth/search`，弹出结果浮层：
  - 顶部提示检测到的疑似理财数据数量。
  - 每页最多显示 50 条。
  - 首列为“标为“不计””复选框，默认勾选。
  - 前端使用 `wealthSelections` 按交易 ID 保存勾选状态，切换分页时状态不丢失。
  - 有结果时显示“确认处理数据”和“取消”；无结果时只显示“确认”。
- 后端在 `autocoin/routers/special_data_processing.py` 新增理财数据接口：
  - `POST /wealth/search` 查询当前用户、未软删除、方向不是 `neutral`、来源为 `alipay`、交易对方为“余额宝”、商品说明 `product` 包含“余额宝”的交易。
  - `POST /wealth/confirm` 接收用户勾选的交易 ID，仅对当前仍符合上述条件的数据更新 `direction = "neutral"`。
- 本功能不新增“已检查”标记；未勾选或取消处理的数据保持原样，下次检查仍会出现。

## 测试覆盖

- `tests/test_api.py` 增加理财数据检查接口测试：
  - 验证命中条件数据会被搜索返回。
  - 验证 `neutral`、软删除、非当前用户、来源不符、交易对方不符、商品说明不含“余额宝”的数据不会返回。
  - 验证确认处理只更新传入且当前仍符合条件的当前用户交易。
