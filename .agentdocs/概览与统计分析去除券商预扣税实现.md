# 概览与统计分析去除券商预扣税实现

## 需求概述

概览页和统计分析页顶部右上角增加“去除券商预扣税”开关。开关默认开启，不持久化；刷新页面后恢复开启。开启时仅调整统计聚合口径，不修改原始交易数据，不影响最近账单、账单明细、导出和导入预览。

## 实现逻辑

- 后端 `/statistics/summary`、`/statistics/monthly`、`/statistics/category` 新增可选参数 `exclude_broker_withholding_tax`，默认 `false`，保持历史兼容。
- 券商预扣税识别条件统一在 `SQLiteRepository` 中维护：
  - `source == "盈透IBKR"`、`direction == "expense"`、`remark` 以 `代扣税` 开头。
  - `source == "MOOMOO"`、`direction == "expense"`、`remark` 以 `非美國居民預扣稅` 开头。
- 汇总统计开启参数时：
  - `total_income` 扣减券商预扣税金额。
  - `total_expense` 排除券商预扣税金额。
  - `transaction_count` 和 `expense_count` 不统计被排除的税费记录。
- 月度统计开启参数时：
  - 每月 `income` 扣减当月券商预扣税。
  - 每月 `expense` 排除当月券商预扣税。
  - 每月 `count` 不统计被排除的税费记录。
- 分类统计开启参数时：
  - `direction=expense` 排除券商预扣税。
  - `direction=income` 从“股息收入”分类金额中扣减同筛选范围内的券商预扣税；如果没有“股息收入”分类，不新增负数分类。

## 前端行为

- `frontend/js/dashboard.js` 和 `frontend/js/stats.js` 页面头部新增同名开关，默认勾选。
- 开关变更后重新加载当前页面统计数据。
- 概览页最近账单仍展示原始交易，不隐藏预扣税记录。
- `frontend/css/styles.css` 新增通用 `.filter-switch` 样式，适配桌面和移动端换行。

## 验证覆盖

- 新增 API 集成测试覆盖默认口径和开启参数后的汇总、月度、收入分类、支出分类统计。
- 测试同时覆盖 IBKR、MOOMOO 预扣税识别，以及非目标来源和非税费券商支出不受影响。
